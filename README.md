README.md – Project 1
E-Commerce Sales Analysis using Python
Project Overview

This project performs an end-to-end data analysis on the Brazilian E-Commerce (Olist) dataset. The objective is to analyze sales performance, identify business trends, evaluate customer reviews, and generate actionable business insights through data visualization and exploratory data analysis.

The project includes data cleaning, merging multiple datasets, sales analysis, visualization, dashboard creation, and business recommendations.

Objectives
Understand the Olist E-Commerce dataset.
Perform data cleaning and preprocessing.
Merge multiple datasets for comprehensive analysis.
Analyze sales trends and customer behavior.
Create interactive visualizations and dashboard KPIs.
Generate business insights and recommendations.
